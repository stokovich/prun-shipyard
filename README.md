# PrUn Shipyard

Ship configurator and order form for Prosperous Universe: pick the parts, see the materials (as the in-game
blueprint counts them), the price (CP MOR + markup) and the expected delivery time, and send an order.

Live page: https://stokovich.github.io/prun-shipyard/

`index.html` is a single self-contained file built from the project sources (`tools/build_standalone.py`);
edit the sources there, not this file.
